Each dataset the lightbox shows is a run directory under runs/<run-id>/: 
runs/<run-id>/
├── site-data.json                    # built rows (entities/rows/stats/labels/thresholds)
├── renders/<pair>-{up,ours}-a<i>.png  # harness shots (any azimuth count)
├── renders/<pair>-{up,ours}.inventory.json / .gif
├── tex-images/<pair>-{up,ours}.png   # decoded mip0 for texture pairs
├── upstream/<entity>/<platform>/…    # upstream bundle bytes
├── ours/<entity>/<platform>/…        # our bundle bytes
└── analysis/pairs.jsonl              # run-relative ours_path/upstream_path per pair
The pipeline stages that fill it (resolve → fetch → ours → pair → render → classify → build) are described in pipeline/README.md. Once at least one run exists, this server's / lands on the lightbox instead of here.
